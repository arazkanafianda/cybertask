# Cybersecurity Event Planner

A simple task manager for planning cybersecurity events. Track event names, dates, status, and notes.

## Requirements

- PHP with PDO SQLite enabled
- A web browser

## Project files

```text
project-folder/
├── index.php    # Page, event actions, and HTML
├── db.php       # SQLite connection and table setup
├── style.css    # Page styling
├── README.md    # Project instructions
└── events.db    # Created automatically when the app runs
